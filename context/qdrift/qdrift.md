# qDRIFT: legacy collection entry point

This preserved collection routes to the maintained
[randomized-method wiki](../randomized_methods/wiki/index.md) and
[source inventory](source_inventory.md). It contains parallel conversions and
citation-discovery surveys, not a separate executable method family.

For standard qDRIFT, use key point `qdrift-randomized-scaling`: probabilities
are proportional to absolute coefficient weights; the standard expected-channel
error depends on total weight, evolution time, and sample count. Holding the
coefficient sum fixed is essential when discussing absence of an explicit
term-count factor. A single trajectory, an expected channel, and a finite
empirical ensemble have different error meanings.

No universal circuit-depth superiority or device speedup is asserted here.
Any advantage depends on the comparator, error metric, coefficient norm,
synthesis, and workload. The former summary's unconditional asymptotic depth
and physical-speedup claims have not been promoted into maintained evidence.
The title/header identities and unknown acquisition/version state of all nine
legacy Markdown paths are recorded in the inventory. Citation survey rows are
only discovery leads. Scientific review remains pending.
