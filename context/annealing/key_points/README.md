# Annealing Key Points

Structured concepts here describe adiabatic conditions and quantum annealing
scope, with evidence links to local raw sources. They support reasoning about
paths and state-preparation goals rather than treating a propagator as proof
of optimization success.

OpenQEvo currently provides experimental dense `annealing` and
`adiabatic_evolution` methods with different input/schedule contracts. See the
[wiki](../wiki/index.md) for their implementation boundaries. Neither method's
availability establishes hardware support or scientific approval.
