# Annealing And Adiabatic Evolution

This wiki collection will cover annealing and adiabatic quantum evolution strategies.

## Current status

No native annealing method is implemented in OpenQEvo yet. This collection exists to keep schedule-based evolution in scope without mixing it with VQE-style optimization workflows.

## Scope

- Adiabatic state evolution.
- Hamiltonian interpolation schedules.
- Annealing-style evolution primitives and backend constraints.

## Evidence state

Seed raw papers have been added for adiabatic quantum computation, adiabatic quantum computing review material, and quantum annealing. Initial key points now cover schedule/gap constraints and quantum annealing scope.
