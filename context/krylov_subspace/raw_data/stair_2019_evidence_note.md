## Supported scope

MRSQK uses real-time-evolved reference states as a nonorthogonal basis and
requires overlap and projected-Hamiltonian information. Reference selection
addresses linear dependence. These quantum algorithm ingredients differ from
OpenQEvo's classical propagator and imply no measured device advantage here.
