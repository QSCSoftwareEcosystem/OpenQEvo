# Software Raw Data

This directory stores local Markdown copies or source-derived notes for
software behavior used by OpenQEvo adapters and recommendation execution.

These files are Layer 0 software evidence. They are meant to preserve API
signatures, parameter names, backend assumptions, and execution behavior so
external AS/RAG tooling can cite software contracts directly. Human-readable
synthesis belongs in `../wiki/` and method metadata belongs in
`../../methods/`.

HTML documentation pages were converted with MarkItDown without the Marker PDF
plugin. Repository README files that were already Markdown are stored directly.
