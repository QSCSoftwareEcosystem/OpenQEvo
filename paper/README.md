# OpenQEvo manuscript source

This directory contains the source for the first review draft of the OpenQEvo
publication. It is deliberately kept as Markdown while authorship, target
venue, institutional wording, and scientific approval are being decided.

- [Manuscript](openqevo_equal_budget_benchmarks.md) — review draft based on
  the software-frozen 2026-09-01 benchmark bundle.
- [Frozen study](../experiments/publication_study/README.md) — protocol,
  verifier, raw records, derived summary, figure, and integrity manifest.

The manuscript is not a submitted preprint or a statement of scientific
approval. Before submission, resolve the marked author, affiliation,
acknowledgment, licensing, citation, venue, and reviewer items.
